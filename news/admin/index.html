1 · Connect to GitHub no token

A GitHub access token is what actually lets this page publish. It is stored only in this browser — never on the site.

How do I create the token?
  1. GitHub → your avatar → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Resource owner: VENR-bit  ·  Repository access: Only select repositories → OneSite.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate, copy the token, paste it above, and click Save & verify.
  5. Set an expiry you're comfortable with; when it lapses, repeat and paste the new one.
