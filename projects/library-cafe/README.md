# Rideekanda Forest Monastery — Library Cafe Design Plan

A donor-facing web page showcasing the architectural design plan for the library cafe at Rideekanda Forest Monastery.

## Features

- Interactive 3D model viewer (Shapr3D embed)
- Image gallery with lightbox (14 architectural renders)
- Furniture & furnishings needed list
- Embedded YouTube project video
- Fully responsive (mobile, tablet, desktop)
- Single self-contained HTML file — no build tools required

## Furniture Items Needed

- Book Racks & Shelving
- Wall-Mounted Reading Table & Chairs
- Veranda Table & Chairs
- Outdoor Timber Deck
- Pantry Cupboard
- Sofa & Lounge Seating

## Deployment

This is a static site — deploy to GitHub Pages, Netlify, or any static host:

1. Push this repository to GitHub
2. Go to **Settings > Pages**
3. Set source to **main** branch, root folder
4. The site will be live at `https://<username>.github.io/rideekanda-library-cafe/`
